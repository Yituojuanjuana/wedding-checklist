# 婚礼备婚清单

2027 年 2 月 1 日（周一）婚礼的纵向时间轴：已完成的前置习俗 4 项、婚礼前一周（1 月 25 日至 31 日，逐日 6 项）与婚礼当天（05:30–21:20，22 个时间节点），共 68 条记录。

## 功能

- 逐项勾选完成，实时更新顶部环形进度与完成数
- 勾选状态保存在浏览器 localStorage，刷新后保留
- 单文件页面，无外部依赖，可离线双击打开
- 响应式布局，桌面端为左侧时间轴，手机端收窄为单列

## 在线访问

GitHub Pages：https://yituojuanjuana.github.io/wedding-checklist/

## 本地使用

打开 `index.html` 即可。取消勾选可撤销完成状态；清除浏览器数据会同时清除已保存的进度。
